# Frezanz Research Workspace

A living research environment for connected ideas, questions, problems, hypotheses, models, experiments, comparisons, learning, sources, and artifacts.

Start with [GUIDE.md](GUIDE.md).

Core loop:

Questions → Problems → Hypotheses → Concepts → Thinking Processes → Models/Architectures → Experiments → Evidence → Comparisons → Learning → new Questions.

The repository is organized around context and relationships, not isolated notes. Each substantial item should make clear what it is, why it matters, where it belongs, what it connects to, what supports it, and what changed because of it.
