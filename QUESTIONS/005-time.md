# Time — Interrogation

## Current target
Extract the project-specific meaning of “time” before adopting conventional definitions.

## Statements requiring testing

### A. Time and change
- Is time a measure of change, or is change a relation between states and time only one possible parameter?
- Could there be change without any temporal ordering?
- Could there be temporal ordering without measurable change?
- Does “change” require comparison, or does comparison merely reveal change?

### B. Timeline / identity
- What exactly belongs to an object's timeline: birth, every state, every interaction, causal ancestry, location, or all of these?
- Does an object need a beginning and end to possess a timeline?
- Can two objects occupy the same temporal position but remain distinct?
- Can one object have multiple relevant timelines depending on which property is tracked?

### C. Uniqueness
- What makes two things different: intrinsic properties, location, state, history, relations, or identity labels?
- If two particles are physically indistinguishable, in what sense are they individually unique?
- Is uniqueness absolute, relational, or observer-dependent?

### D. Relativity / perspective
- When you say time depends on the object, do you mean different elapsed durations, different ordering, different clocks, different histories, or different perspectives?
- Is the “timeline” an intrinsic property of the object, or a relation between object and spacetime/environment?
- What survives a change of reference frame?

### E. Fundamental status
- If nothing changed anywhere, would time still exist in your concept?
- If all clocks disappeared, would time disappear?
- If no observer existed, would time exist?
- If an object were perfectly isolated, what would constitute its timeline?
- Is time prior to change, generated by change, or abstracted from change?

### F. Formalization targets
Potential candidates:
- state trajectory
- change relation
- event ordering
- proper time
- worldline
- history
- causal structure
- reference-frame transformation

No candidate formula should be declared foundational until its domain and meaning are explicit.
