# Time — Formula Candidates

## Status
NEW_FORMULA_TARGET / NOT_YET_FORMALIZED

## Candidate 1: Change as a relation between states
For an object/system with state S:
ΔS = S_2 − S_1

This is only a generic mathematical representation of difference, not yet a definition of time.

## Candidate 2: Time as a parameter for change
S = S(t)

This expresses that system state depends on a parameter t. It does not establish what t ontologically is.

## Candidate 3: Object history
H_a = {(t_i, S_i)}

A provisional history of object a as a sequence of state-time pairs.

## Candidate 4: Reference-dependent elapsed time
Δt_R(a; R)

A placeholder for elapsed temporal measure assigned to process a relative to reference R.

## Open issue
The project asks whether there is a deeper relation from which both “change” and “time” emerge. That is not established yet.
