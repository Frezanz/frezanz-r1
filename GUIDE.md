# Guide

## Purpose

This repository is a structured research environment. It should preserve ideas while making their context, provenance, relationships, differences, and evolution visible.

## First rule

Every substantial item should answer, as appropriate:

- What is it?
- Why does it exist?
- Where does it belong?
- What does it depend on?
- What does it support or contradict?
- What is its basis?
- What does it affect?
- What should happen next?

## Sections

- QUESTIONS — things that need answers.
- PROBLEMS — limitations, errors, contradictions, bottlenecks, unknowns.
- HYPOTHESES — proposed explanations or claims that can be challenged.
- CONCEPTS — definitions and conceptual building blocks.
- THINKING_PROCESSES — observations and models of reasoning, problem solving, representation, and decision processes.
- TOPICS — external knowledge domains relevant to the work.
- FORMULAE — formal expressions, variables, assumptions, derivations, and uses.
- MODELS — abstract explanatory or computational models.
- ARCHITECTURES — system structures and alternatives.
- EXPERIMENTS — tests designed to distinguish possibilities or produce evidence.
- COMPARISONS — explicit comparison of items across meaningful dimensions.
- LEARNING — reusable knowledge, skills, methods, lessons, mistakes, structures, and artifacts.
- SOURCES — provenance registry for external and internal sources.
- STATUS — current project state and direction.
- DECISIONS — important choices and their reasoning.
- HISTORY — changes and evolution over time.
- ARTIFACTS — outputs produced by the research.
- TOOLS — software, instruments, and methods used.
- ARCHIVE — material kept for historical context but not currently active.

## Relationships

Use explicit relationships when useful:

supports, contradicts, derived_from, tested_by, tests, alternative_to, depends_on, related_to, modifies, replaces, inspired_by, uses, produces, affected_by.

## Provenance

A source is not necessarily an external website. It can be a paper, book, dataset, experiment, observation, formula, concept, architecture, internal document, or another repository item.

Link sources from the items that use them. Keep SOURCES as the central registry/index.

## Evidence language

Distinguish among fact, sourced claim, observation, inference, hypothesis, and speculation.

## Navigation

Do not rely on folder names alone. Links, relationships, indexes, status pages, and comparisons should make the research traversable from any important item.

## Adding research

1. Capture the item.
2. Give it context.
3. Link related items.
4. Record sources.
5. State uncertainty.
6. Compare alternatives when relevant.
7. Update status/history when the state changes.
